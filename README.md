# 地域別の樹木診断基準

日本の街路樹・公園樹について、地域・管理者・診断段階に合う基準と原典を探すためのskillと資料集です。基準の内容、適用条件、版、出典ページ、未確認事項をまとめています。

**試用版 v0.1.3。行政の公式資料ではありません。** 実際の案件では管理者・対象施設・契約の指定版を確認してください。数値だけで個木の安全性や伐採を確定するものではありません。

## ダウンロードと導入

[試用版ZIPとSHA-256](https://github.com/ogawayugo/regional-tree-criteria/releases/tag/v0.1.3)をダウンロードしてください。GitHubが自動生成するSource codeとは別に、導入用ZIPを添付しています。

1. ZIPを展開する。
2. `regional-tree-criteria` フォルダ全体を自分のホームフォルダの `.agents/skills/` に置く。
3. Codexで `$regional-tree-criteria` を指定する。

詳しくは[導入手順](INSTALL.md)を参照してください。AIなしで読む場合は、展開後の `index.html` をブラウザで開きます。検索はネット接続なしで使えます。原典の閲覧にはネット接続が必要です。

## 根拠付き定型回答の試作

大阪市・北海道・日立市の確認済み12項目について、管理者・対象・診断段階・版・照会項目・範囲が一致した場合だけ、出典付きの定型回答を返します。19カードの資料索引とは区別しています。

`python scripts/answer_criteria.py --list` で対応条件を確認できます。[使い方と限界](references/answer-workflow.md)に入力例、回答検査、未収録時の扱いを記載しています。AI APIや追加パッケージは不要です。

## 質問例

- 大阪市が管理する公園樹の判定区分、適用条件、出典ページを教えて。
- 北海道の三次診断にB3はある？二次との違いも示して。
- 埼玉県の基準で、出典付きで回答できるものは収録されている？
- 日立市の平和通りで腐朽率40%ちょうどの場合、原典にはどう書かれている？

任意のPython検索補助は `python scripts/find_criteria.py "大阪市 公園"` で実行できます。Python 3.9以上、標準ライブラリのみ。PythonがなくてもMarkdownとHTMLを利用できます。

## 確認範囲と制限

v0.1.3は出典と該当位置を持つ説明に絞った版です。原典本文の全件再照合、最新性、各資料の利用条件、別PCのCodexへの実インストールは確認しきれていません。

日立市の「40%超」と「40%以上」の資料内不一致、大阪市の港湾局所管の除外・診断段階別区分を記録しています。原典にある不一致を独自の判断で統一しません。
