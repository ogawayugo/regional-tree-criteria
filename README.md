# 地域別の樹木診断基準

日本の街路樹・公園樹について、地域・管理者・診断段階に合う基準と原典を探すためのskillと資料集です。基準の内容、適用条件、版、出典ページ、未確認事項をまとめています。

**試用版 v0.1.1。行政の公式資料ではありません。** 実際の案件では管理者・対象施設・契約の指定版を確認してください。数値だけで個木の安全性や伐採を確定するものではありません。

## ダウンロードと導入

[試用版ZIPとSHA-256](https://github.com/ogawayugo/regional-tree-criteria/releases/tag/v0.1.1)をダウンロードしてください。GitHubが自動生成するSource codeとは別に、導入用ZIPを添付しています。

1. ZIPを展開する。
2. `regional-tree-criteria` フォルダ全体を自分のホームフォルダの `.agents/skills/` に置く。
3. Codexで `$regional-tree-criteria` を指定する。

詳しくは[導入手順](INSTALL.md)を参照してください。AIなしで読む場合は、展開後の `index.html` をブラウザで開きます。検索はネット接続なしで使えます。原典の閲覧にはネット接続が必要です。

## 質問例

- 大阪市が管理する公園樹の判定区分、適用条件、出典ページを教えて。
- 北海道の三次診断にB3はある？二次との違いも示して。
- 埼玉県の判定本文が未取得なら、何が足りないか教えて。
- 日立市の平和通りで腐朽率40%ちょうどの場合、原典にはどう書かれている？

任意のPython検索補助は `python scripts/find_criteria.py "大阪市 公園"` で実行できます。Python 3.9以上、標準ライブラリのみ。PythonがなくてもMarkdownとHTMLを利用できます。

## 確認範囲と制限

v0.1.1では別フォルダへの展開、検索14ケース、ブラウザ検索6ケース、UTF-8出力、内部リンク、ファイルハッシュ、Edgeでの初期表示を確認しました。別PCのCodexへの実インストール、全原典の最新性、全判定表の画像照合は未完了です。

日立市の「40%超」と「40%以上」の資料内不一致、大阪市の港湾局所管の除外・診断段階別区分を記録しています。原典にある不一致を独自の判断で統一しません。

## 修正・更新

修正の提案は[Issues](https://github.com/ogawayugo/regional-tree-criteria/issues)へ、カードID、資料の版、該当ページ、確認した内容を添えてください。樹木の所在地・個人情報・非公開の契約資料は投稿しないでください。

更新履歴は[CHANGELOG](CHANGELOG.md)。`manifest.json` は配布用skillファイルのハッシュ一覧で、公開案内用README等は対象外です。
